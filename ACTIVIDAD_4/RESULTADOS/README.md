# Resultados del análisis

Esta carpeta es el destino de los resultados generados al ejecutar `ACTIVIDAD_4/SCRIPT_R/enfermedad_coronaria.R`. Los resultados no se incluyen como cifras de ejemplo para evitar atribuir resultados no calculados al dataset.

El script genera archivos como `metricas_modelo.csv`, `coeficientes_modelo.csv`, `comparacion_modelos.csv`, `matriz_confusion.txt` y gráficos PNG. Ejecuta el análisis localmente con el CSV y luego añade aquí los archivos generados si el repositorio debe contenerlos.
