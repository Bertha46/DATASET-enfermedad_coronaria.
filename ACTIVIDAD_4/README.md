Este directorio contiene el script de análisis en R y un informe base para el ejercicio de predicción de enfermedad coronaria a diez años con los datos de Framingham.

## Archivos
- `SCRIPT_R/enfermedad_coronaria.R`: explora los datos, imputa faltantes con medianas estimadas en entrenamiento, ajusta y compara modelos logísticos, y guarda resultados.
- `DOCUMENTO_SOPORTE/Informe_Framingham.md`: informe para completar con los valores producidos al ejecutar el script.

## Cómo ejecutar
1. Coloca el CSV en la carpeta `DATASET/` o en la raíz del repositorio. El script busca `enfermedad_coronaria (1).csv` o `enfermedad_coronaria.csv`.
2. Abre el proyecto en RStudio y ejecuta `SCRIPT_R/enfermedad_coronaria.R`.
3. Revisa los archivos generados en `RESULTADOS/` y completa en el informe los campos entre corchetes.

El informe no contiene métricas inventadas: los valores y conclusiones específicas deben basarse en la ejecución real del script con el CSV correcto. El modelo es una actividad académica y no es una herramienta de diagnóstico médico.
